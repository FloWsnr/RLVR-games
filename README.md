# RLVR-physics

Trainer-agnostic executable verifier tasks for RLVR.

This repo is intentionally early-stage. The firm commitments are in
[SPEC.md](SPEC.md): scalar executable tasks, trainer-owned concurrency,
authoritative verifier logic, and useful trajectories. Exact APIs, dataclass
fields, and module layout are design bets until the first single-step and
stateful task prototypes prove them.
